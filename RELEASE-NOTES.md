# ONI RCON desktop 1.17.0

Start-together from the console, for Reclaimer 0.10.9 servers.

## New

- **Start together (experimental).** F3 › SERVER › START TOGETHER switches a Reclaimer 0.10.9+ server to the Xbox 360-style start: a game begins when everyone is ready, after a wait you choose, or when the lobby hits its limit. You can also set a short spawn hold. The setting applies to that one server only, and out-of-range values are refused. ([#75](https://github.com/viik2k/oni-rcon/pull/75))

## Upgrading

Desktop installs update in place from the app. Config and plug-ins work unchanged.
